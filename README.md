# 작심삼일 (Jaksimsamil)

작심삼일의 소개 홈페이지와 공개 정책 문서를 관리하는 저장소입니다.

## 공개 사이트 바로가기

- [소개 홈페이지](https://ggongrae.github.io/jaksimsamil-policy/)
- [개인정보처리방침](https://ggongrae.github.io/jaksimsamil-policy/privacy_policy.html)
- [서비스 이용약관](https://ggongrae.github.io/jaksimsamil-policy/terms.html)
- [공지사항](https://ggongrae.github.io/jaksimsamil-policy/notices.html)

위 링크를 클릭하면 실제 공개된 사이트를 바로 확인할 수 있습니다.

## 공지사항 작성·수정

[notices.html](https://github.com/GGONGRAE/jaksimsamil-policy/blob/main/notices.html)을 GitHub에서 수정하고 저장하면 공개 목록에 반영됩니다. [작성 방법과 양식](NOTICE_GUIDE.md)을 참고하세요.

앱에서는 **프로필 → 도움말 → 공지사항** 버튼을 누를 때만 웹페이지를 엽니다. 시작·복귀·백그라운드 공지 확인, 새 공지 배너·뱃지·푸시는 추가하지 않습니다.
